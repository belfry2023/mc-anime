# mc-anime 联机指南（服务器 + 朋友一起玩）

## 方案一览

| 方案 | 适合场景 | 需要什么 |
|---|---|---|
| A. 专用服务器（推荐，本文件夹） | 长期一起玩、随时上线 | 一台常开的电脑 + 一次联网安装 |
| B. 游戏内「对局域网开放」 | 临时玩一晚上 | 双方在同一局域网（或虚拟局域网） |
| C. 虚拟局域网（Radmin VPN / ZeroTier / 易联达） | 跨城市、不想折腾路由器 | 双方各装一个虚拟局域网软件 |

---

## 方案 A：专用服务器

1. 把 `mc-anime-server` 文件夹拷到当服务器的电脑（最好是有线网、常开的机器）。
2. 双击 `服务器安装.bat`，等它跑完（第一次需要联网下载 Forge 库，几分钟）。
3. 双击 `server-start.bat` 开服。看到 `Done (xx.xxxs)! For help, type "help"` 就是开好了。
4. 查本机内网 IP：命令行输入 `ipconfig`，找「IPv4 地址」（形如 `192.168.1.23`）。
5. 朋友在客户端：
   - 多人游戏 → 添加服务器 → 地址填 `192.168.1.23:25565`（同一局域网）
   - 或填 `你的公网IP:25565`（跨网，需要做端口映射 / 或用方案 C 的虚拟局域网 IP）

### 防火墙（只需要做一次）

如果朋友连不上，九成是 Windows 防火墙拦了 25565。用**管理员** PowerShell 跑：

```powershell
New-NetFirewallRule -DisplayName "Minecraft Server 25565" -Direction Inbound -Protocol TCP -LocalPort 25565 -Action Allow
New-NetFirewallRule -DisplayName "Minecraft Server 25565 UDP" -Direction Inbound -Protocol UDP -LocalPort 25565 -Action Allow
```

### 修改服务器设置

`server.properties` 里常用项：

- `online-mode=false`：不校验正版（朋友用离线启动器也能进；介意安全可改 true，但要求全员正版）
- `max-players=8`：最大人数
- `view-distance=8` / `simulation-distance=6`：视野与模拟距离，机器弱就调小
- `difficulty=hard`：难度
- `motd=`：服务器列表里显示的名字

内存：编辑 `memory.txt`（默认 6G）；机器内存 8G 的话建议 4G。

## 方案 B：游戏内「对局域网开放」

最快、零安装：

1. 主机先进单人世界，按 `Esc` →「对局域网开放」→ 端口默认 25565 → 开始。
2. 主机把内网 IP 告诉朋友，朋友用「直接连接」填 `192.168.x.x:25565`。
3. 缺点：主机不能退出世界；主机一走服务器就没了。

---

## 方案 C：虚拟局域网（跨城市首选）

1. 双方都装 **Radmin VPN**（免费）或 **ZeroTier**，加入同一个网络。
2. 主机开服（方案 A）或「对局域网开放」（方案 B）。
3. 朋友连接主机在该虚拟网络里的 IP（Radmin VPN 面板上能看到，形如 `26.x.x.x`）。
4. 不需要动路由器、不需要公网 IP。

> 想更省事也可以用 **易联达 / 浩方 / PlayIt.gg** 这类联机平台，原理相同。

## 常见问题

**Q：朋友连上后一直被踢 / 版本不符？**
A：双方必须都是这套 mc-anime 客户端（同样的 mods 与 Forge 1.20.1-47.4.29）。用同一个安装包装一遍最稳。

**Q：服务器控制台刷 `Can't keep up`？**
A：机器吃不消。把 `view-distance` 降到 6、`simulation-distance` 降到 4，或减少同行人数。

**Q：服务器启动报 `You need to agree to the EULA`？**
A：把 `eula.txt` 里的 `eula=false` 改成 `eula=true`（安装脚本已自动写好）。

**Q：存档想从单人搬过来？**
A：把单人的 `game\.minecraft\saves\世界名` 整个文件夹拷到服务器目录，改名为 `world`（对应 `server.properties` 的 `level-name`）。

**Q：能不能让服务器一直开着？**
A：可以，把 `server-start.bat` 设进「任务计划程序」开机自启，或在服务器控制台输入 `stop` 安全关服（别直接关窗口）。
